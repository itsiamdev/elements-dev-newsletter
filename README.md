# DevPulse Weekly — Elements Template

An original developer newsletter email template built with the [Unlayer (Elements)](https://www.unlayer.com/) email editor. Designed for the **Build with Elements Challenge**, DevPulse Weekly demonstrates how to combine Elements' powerful visual editor with a custom, production-ready email template.

## What It Does

DevPulse Weekly is a fully editable email newsletter template that developers can customize, extend, and export. It ships with a polished pre-built design that covers the most common newsletter sections:

- **Header** — Branded masthead with issue number
- **Hero** — Featured story with headline, summary, and primary CTA
- **Featured Articles** — Three curated posts with category tags
- **Tool of the Week** — Spotlight card for developer tools
- **Quick Tips** — Numbered list of actionable developer tips
- **Call to Action** — Subscribe/share section
- **Footer** — Social links and attribution

### Live Preview

Edit the template in the left panel and see changes instantly in the right-hand preview. The preview uses an isolated iframe so styles render exactly as they would in a real email client.

## Getting Started

### Prerequisites

- Node.js >= 18
- npm (or pnpm/yarn)

### Install & Run

```bash
# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build

# Preview production build
npm run preview
```

### Using the Template

1. Open the app in your browser (default: `http://localhost:5173`)
2. The editor loads with the pre-built DevPulse Weekly template
3. Drag, drop, and customize blocks in the Elements editor
4. Changes appear in real-time in the Preview panel
5. Click **Export HTML** to download the final template
6. Click **Reset Template** to restore the original design

## Template Design Details

The template is defined as a design object in `src/components/Editor.jsx` and loaded into Elements via `unlayer.loadDesign()`. It uses:

- **600px container width** for optimal email client compatibility
- **Email-safe HTML tables** generated by Elements
- **Responsive breakpoints** that adapt to mobile viewports
- **Modern color palette** (slate navy `#0f172a`, cyan accent `#06bed6`)
- **Web-safe typography** with system font stacks

## How Elements Powers This Project

- **`unlayer.init()`** — Initializes the editor with `displayMode: "email"` and a modern dark appearance
- **`unlayer.loadDesign()`** — Loads the pre-built DevPulse Weekly template on startup
- **`unlayer.exportHtml()`** — Exports the final editable HTML with inline styles
- **Event listeners** (`design:loaded`, `design:updated`) — Keep the live preview in sync with the editor
