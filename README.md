# DevPulse Weekly — Elements Template

An original developer newsletter email template built with [Unlayer (Elements)](https://www.unlayer.com/) React components. Designed for the **Build with Elements Challenge**, DevPulse Weekly demonstrates how to compose emails with `@unlayer/react-elements` and render them to production-ready HTML.

## What It Does

DevPulse Weekly is a fully editable email newsletter template built declaratively with Elements components. It ships with a polished design covering the most common newsletter sections:

- **Header** — Branded masthead with issue number
- **Hero** — Featured story with headline, summary, and primary CTA
- **Featured Articles** — Three curated posts with category tags
- **Tool of the Week** — Spotlight card for developer tools
- **Quick Tips** — Numbered list of actionable developer tips
- **Call to Action** — Subscribe/share section
- **Footer** — Social links and attribution

### Live Preview

Click **Render Preview** to generate the email HTML from the Elements component tree and display it in an isolated iframe. Click **Export HTML** to download the final template file.

## Getting Started

### Prerequisites

- Node.js >= 18
- npm (or pnpm/yarn)

### Install & Run

```bash
# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build

# Preview production build
npm run preview
```

### Using the Template

1. Open the app in your browser (default: `http://localhost:5173`)
2. Click **Render Preview** to generate and preview the email HTML
3. Click **Export HTML** to download `devpulse-weekly-template.html`

## Template Design Details

The template is built with `@unlayer/react-elements` components in `src/App.jsx` and rendered to HTML using `renderToHtml()`. It uses:

- **600px container width** for optimal email client compatibility
- **Email-safe HTML tables** generated by Elements
- **Responsive breakpoints** that adapt to mobile viewports
- **Modern color palette** (slate navy `#0f172a`, cyan accent `#06bed6`)
- **Web-safe typography** with system font stacks

## How Elements Powers This Project

- **`<Email>`** — Root wrapper for email-safe HTML (tables for Outlook, Gmail, Yahoo)
- **`<Row>` / `<Column>`** — Layout containers with `ColumnLayouts` for responsive columns
- **`<Heading>` / `<Paragraph>` / `<Button>`** — Content components with email-safe styling
- **`<Divider>` / `<Html>` / `<Social>` / `<Menu>`** — Additional Elements components for structure and navigation
- **`renderToHtml()`** — Converts the component tree into a complete HTML document with MSO conditional comments
